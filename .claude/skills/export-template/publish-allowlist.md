# Publish-gate allowlist — adjudicated-benign matches

Lines the personal-strings probe of `publish_guard.py` may ignore, each with its one-line justification. The probe parses this file, so its format is executable, not decorative.

**Format** — `- <key> :: <where it matches> :: <why benign>`, one entry per line.
- **Key**: either the literal string, when the string is itself public-safe, or a placeholder standing for a derivation class, when it is not. The placeholders are `<agent name>` · `<repo owner handle>` · `<licence holder's legal name>` · `<owner email token>` · `<machine account name>` · `<vault path component>` · `<extra gate string>`; anything else in angle brackets halts the gate. A placeholder covers a needle whenever that class is among the classes the needle was derived from, and a needle can carry several.
- **Where**: every file the entry covers, each in backticks, payload-relative. An entry that names no file halts the gate: an allowance floating free of its files would let a string spread from the line it was adjudicated for into any file that later quoted it, and still report clean.
- **Counts**: a **provisional** entry — an owner-ruled deferral of a class fix to a named release — writes `PROVISIONAL, expires at vX.Y` in its Where field and a per-file count after each path, `` `path` (N) ``. **N counts occurrences, not matching lines.** A permanent entry carries no counts and is uncapped inside its files. A hit outside an entry's files, or above a provisional count, stays unallowlisted and halts the publish.
- **Expiry**: the release named in a provisional entry removes that entry; `publish_guard.py --release vX.Y` turns a reached expiry into a gate failure, and every run reports the pending ones.

**Rules** — an entry describes the framework line that matches and never quotes personal data; entries must themselves be public-safe, because this file ships with the skill; add one only after a real adjudication, once, permanently. Entries the probe reports as *inert* matched no needle this run: they are kept, not deleted, since a retired string can return.
