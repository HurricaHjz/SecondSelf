# Generated capability register presentation

This is documentation for the generated page, not seed input. `adopt_render.py` generates the entire page from validated data, and the sole writer publishes it. Seed uses the sole writer and contains no rows or legacy exemptions. The page retains its address and includes metadata, an edit pointer, categories, route/state/freshness/proof summaries, maintenance holds, typed prose and source provenance.

Layout 1, the first structured layout, prints the revision, commit time and a register-data comment in the body. It stays readable and is reproduced byte for byte for existing tuples, and frozen version 1 data keeps its own renderer.

Layout 2 is the layout the writer emits. The body is constructed once; its exact bytes, from the byte after the closing frontmatter delimiter line to the final newline, are hashed with SHA-256 and declared in the frontmatter as `register-body-sha256: "<64 lowercase hexadecimal characters>"`. The frontmatter also carries `register-revision`, `register-committed` (the proposal timestamp) and `register-data-sha256`. These four fields are renderer-owned and never stored in editable page metadata. The digest is a consistency check, not a signature: the Stop hook leaves the generated page's date alone only when the declaration matches the body it reads, so a hand edit, a stale or copied digest, a missing or malformed declaration all fall through to ordinary stamping, while the writer's complete page, data and receipt checks still refuse the edit.

The writer owns `updated:`. When the rendered body differs from the observed page body or the committed parent's body, `updated:` becomes the later of the proposal's local calendar day, captured with its numeric offset in the proposal timestamp, and the local day of any apply-time instant the operation writes into the body, such as an activation time. Otherwise it is kept. An ordinary request may carry `updated` and `layout_version` only at their current values. A metadata-only typed edit of `audited:` or `confidence:` changes the frontmatter, revision and receipt but not the body, its digest or `updated:`.

Layout 2 ends with a real `## Sources Used` section, listing the link tokens recorded under the source section of typed prose, and a real `## Related` section, listing every distinct recorded local target as a wiki link: linked note links on every row, linked record links on managed rows and local link tokens in typed prose. Unresolved entries and web addresses are not wiki targets. With no recorded local target, Related links the framework's index page as navigation only, never as an add-on record or evidence.
